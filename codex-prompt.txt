Maintain the Chessar Engine Index against the live calibration roster at
https://chessar.org/api/v1/engines/ranked.

1. Verify the exact engine family and current version before changing the index.
2. Keep one version page at docs/<engine-slug>/<version>/index.html for each
   current family, and match that set in docs/index.html.
3. Separate Linux and Windows downloads. Prefer explicitly named, versioned
   release assets and include source and license information where required.
4. Use the authorized upstream download or manual install instructions where
   redistribution is restricted. Preserve the Komodo worker import instructions.
5. Check that version pages and download links resolve after publication.
   Keep stockfish-18 as the latest release while Stockfish 18 is current.
6. Keep credentials out of commands, files, and output. Clean temporary files
   created while preparing or validating releases.
